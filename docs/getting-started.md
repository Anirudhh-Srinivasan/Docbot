# Getting started with Orbit

Orbit is a shared project workspace for small product teams. Create your account at **app.orbit.example**, verify your email, and choose **Create workspace**. Workspace names can be changed later in Settings.

Invite teammates from **Settings → Members → Invite**. Enter their work email and choose Member or Admin. An invite expires after 7 days; an admin can resend it from the Pending invitations list.

To start a project, select **New project**, give it a name, and optionally connect a GitHub repository. Orbit imports repository issues but does not copy source code. The free plan supports up to 3 members and 2 active projects. New workspaces include a 14-day Pro trial; no card is needed to start the trial.

Set your timezone in **Profile → Preferences**. Weekly summaries are emailed on Monday at 9:00 AM in that timezone.
